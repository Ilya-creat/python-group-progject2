## Структура проекта

```
.github/workflows/     - CI/CD конфигурации GitHub Actions
|- flake8.yml          - Проверка программного кода .py на стандарт PEP8

api/                   - Основные API-структуры и обработчики
|- data/*.csv          - Хранилище дата-сетов API
|- .                   - Скрипты для парсинга данных по API
bs4/                   - Модуль парсинга данных
|- data/               - Хранилище дата-сетов BS4
|- .                   - Скрипты для скрапинга данных BS4
logger/                - Настройка логирования и обработка ошибок
|- logs/*.log          - Хранилище логов
|- logger.py           - Скрипт логгирования
routes/                - Маршруты подключаемых внешних сервисов
sessions/
|- session.py          - Скрипт ререализации сессии для запросов
|- session_settings    - Конфигурация создания сессий
ipynb/                 - Jupyter notebooks анализа данных

.env                   - Переменные окружения
.gitattributes         - Индексирование файлов в системе GIT-FSL
README.md              - Документация проекта
checker.py             - Скрипт программных проверок для парсинга
save_df.py             - Скрипт автосохранения данных дата-сетов
settings.py            - Настройки проекта
setup.cfg              - Конфигурация окружения
requirement.txt        - Зависимости проекта
```

---

## Зависимости проекта

- **pandas** - для работы с табличными данными
- **numpy** - для численных операций и работы с массивами
- **beautifulsoup4** - для парсинга HTML/XML контента
- **python-dotenv** - для загрузки переменных окружения из .env файлов
- **logging** - для настройки логирования
- **ast** - для работы с абстрактными синтаксическими деревьями
- **selenium** - для автоматизации скраппинга данных
